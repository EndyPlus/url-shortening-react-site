# <a href="https://www.frontendmentor.io/challenges/url-shortening-api-landing-page-2ce3ob-G" target="_blank">URL shortening API landing page 🔗</a> | FRONTEND MENTOR CHALLENGE

## Tech stack:

- ReactJS 🔵
- Tailwind 🔵
- Vite 🟣

## Tasks:

- Shorten any valid URL | ✅
- See a list of their shortened links, even after refreshing the browser | ✅
- Copy the shortened link to their clipboard in a single click | ✅
- Receive an error message in form | ✅
- View the optimal layout for the interface depending on their device's screen size | ✅
- See hover and focus states for all interactive elements on the page | ✅

## How to start project:

- Clone/download a project;
- In terminal run `npm install`;
- After installing all dependencies, run `npm run dev`;

_Check "package.json" file to see all dependencies and scripts if you need._
